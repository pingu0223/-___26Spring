# 错误大集合
## 首先：关于整体框架问题
> 我的思路：依靠for循环找n-1个结点的最短路径且最开始先把最初结点整完

> 实际上应该：借助while(!pq.empty())直接判断有没有找好最短路径，且最开始不要动我们的最初结点
## 接着：关于最短路径条数更新问题
> 我的思路：当更新时cnt[p]=1;当找到一条新路时cnt[p]++;

> 实际上应该：更新时cnt[p]=cnt[curr];找到新路时cnt[p]+=cnt[curr]；

> 错误原因：忘记了curr也可能有多条道路

## 然后：关于cnt初始化问题
> 我的思路：忽略了最开始对cnt[first]=1的初始化

> 实际上应该：初始化
