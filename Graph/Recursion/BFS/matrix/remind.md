# 关于邻接矩阵的BFS需要注意的点

## BFS的核心

### 思路解析

   从起始点**一层一层**遍历，类似树的**层次遍历**。要用到**queue**
   
### 敲代码小思路

1. 我们需要判断起始点是不是合法的
2. 我们需要记录图上的点有没有被访问过，所以新建了一个visited的数组
3. 在循环过程中，我们需要一个stl去承装上一个结点所邻接的点，考虑到层次遍历使用的是queue，所以我们也用**队列**去承载
4. 判断过程中，要判断结点没被访问过且与current结点相邻接。

## 代码易错片段提醒
1. 应该引用矩阵

```cpp
void BFS(vector<vector<long long>>&matrix,int start)
```

2. 应该在入队时更新visited内的数值
   
```cpp
q.push(i);
visited[i]=true;
```

否则，可能造成元素**重复入队**.
